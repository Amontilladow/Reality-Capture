# Discrepancies

These are the differences between the build brief and the ADM PDF (*Standards & Specifications for Planning Data Submission v1.18.2*, SHA-256 `125f1122…b2fd`), plus inconsistencies inside the PDF itself. Where the brief and the PDF disagree, **the PDF wins**. Each item needs confirmation from the official template or ADM SDD (gis.support@adm.abudhabi.ae).

| ID | Where | Brief says / PDF says | What the tool does | Needs |
|---|---|---|---|---|
| X-01 | Table 6 rows 40, 44 (p.14) | The brief's Roads checklist omits **RailRoadEdgeDetail** and **RailRoadCenterlineDetail**. The PDF lists both as point attribute-block layers (colours 133 and 161). | Both are in the manifest. | Nothing (PDF wins). |
| X-02 | Table 6 row 10 vs §6.2.5 (p.13, p.20) | The layer is `RoadlayByDetail` in Table 6 (the casing the brief notes). §6.2.5 names the block `RoadlaybyDetail` and the layer `RoadLaybyDetail`. The heading spells the feature `RoadLayby`, while the table has `RoadLayBy`. | The layer name follows Table 6. The other spellings are recognised as aliases (ADM-LYR-007 warning). The block name follows §6.2.5. | Official template |
| X-03 | Table 6 row 3-4 vs §6.2.1 (p.12, p.18) | `RoadCenterLine` / `RoadCenterLineDetail` (table) vs `RoadCentreLine` / block and layer `RoadCentreLineDetail` (§6.2.1). | The layer follows the table. `RoadCentreLine*` is accepted as an alias. The block is `RoadCentreLineDetail`. | Official template |
| X-04 | Table 6 row 20 vs §6.2.10 (p.13, p.22) | `UnderPassDetail` vs block and layer `UnderpassDetail`. | Same approach as X-02. | Official template |
| X-05 | Table 7 row 11 vs §6.3.7 (p.15, p.33) | Layer `BoreHole` vs block and layer `Borehole`. | Same approach as X-02. | Official template |

| X-07 | §4.2 (p.8) | The text says "Date in **Year, Day and Month** format", but the pattern `<YYYYMMDD>` and the examples (e.g. `20131007`) are year-month-day. | Validated as YYYYMMDD with a real calendar date. | ADM confirmation |
| X-08 | §4.2 (p.7-8) | The pattern has `Plot/Roads/Services/additional`, while the bullet has `<Plot/Roads/services>`. | X-12 | §6.3.5 InfrastructureType (p.32) | The list wraps without commas: "Storm Water, Subsurface Drain Sewerage" and "Solid Waste refined Petroleum". | Split as `Subsurface Drain`, `Sewerage`, `Solid Waste`, `refined Petroleum`. | ADM confirmation |

| X-14 | §4.7 note vs §6 rule 3 (p.11-12, p.34) | The Title layer may hold "textual details", but "Text entities shall not be used". | TEXT/MTEXT is allowed on Title only. Elsewhere it is an error (ADM-ATT-010). | ADM confirmation |
| X-15 | Data types (§6) | Mixed vocabulary: Character, Integer, Float, Double, Number, Boolean (Y/N), String. `numofparkings` is lower case in §6.2.18. | Numeric types are parsed as numbers.
