## Unresolved requirements

Rules not fully verifiable today (evidence PENDING_OFFICIAL_CONFIRMATION, implementation PARTIAL / INTERFACE_ONLY / NOT_IMPLEMENTED):

- **DRM-GEN-03** Drawing is in the DRM coordinate system (WGS 84 / UTM 39N or 40N, metres) - PARTIAL. The exact test the QC tool applies is not documented; the tool checks the confirmed declaration and the extent plausibility.
- **DRM-GEN-04** ZoneName / SectorNumber belong to the official lists embedded in the QC tool - NOT_IMPLEMENTED. The official zone and sector lists are compiled into the .FAS and are not published; only consistency between file name and PlotDetail is checked (DRM-ATT-06).
- **DRM-ATT-44** UnitUsageType is a UPC land-use term (QC manual Appendix 1 list 4) - PARTIAL. Several manual pages of this list are images; the reference list is the union of all UPC LandUse terms and the extractable manual text (376 terms).
- **DRM-ATT-49** SpaceNumber data entry in SpaceDetail / WindowDetail is complete (positive integer SpaceNumber with its FloorNumber) - IMPLEMENTED. Trigger inferred from one official report: on the trial draft we flag 10 SpaceDetail blocks where ADM flagged 9 (DISCREPANCIES_BDMS B-17). The official v2.3 report has no such row for DoorDetail, so none is raised there.
- **DRM-ATT-51** SpaceNumbers are progressive (1, 2, 3 ...) in the floor (notification) - IMPLEMENTED. Key note 8 asks for progressive numbers, but the DRM-accepted KHALIFA CITY-...-G skips 5, 20 and 22 and passed with 0 errors, and the spec only requires unique positive integers. Reported as a notification, never an error (DISCREPANCIES_BDMS B-16).
- **DRM-LOG-21** Features lie within their parent (Floor in BuildingOutline, Space/Unit in Floor, BuildingOutline in Plot) - IMPLEMENTED. The manual does not state whether "corresponding" means spatial containment; reported as WARNING. Doors and windows that touch no space are accepted in the SAMPLES.
- **DRM-SPEC-FMT** Submission format DWG, AutoCAD 2006 or later - PARTIAL. Prepared file is DXF R2010; convert to DWG (AutoCAD or ODA File Converter).
- **DRM-SPEC-UNIT** Geometry at full scale in metres (SAMPLES) - SPEC text says centimetres - PARTIAL. The engineer confirms metres; the $INSUNITS header is not enforced because the accepted SAMPLES carry 4 (mm).
- **DRM-SPEC-ENTRY** Special or repeated characters flagged as possible data-entry errors - PARTIAL. M4 heuristic; the QC tool's exact rule is not documented.
