## Unresolved requirements

Rules not fully verifiable today (evidence PENDING_OFFICIAL_CONFIRMATION, implementation PARTIAL / INTERFACE_ONLY / NOT_IMPLEMENTED):

- **ADM-FMT-001** Submission file is AutoCAD DWG, release 2012 or earlier - PARTIAL. Tool writes DXF R2010 (AC1024). DWG requires an external converter (ODA File Converter or AutoCAD) - not available in this build.
- **ADM-NAME-002** ProjectID is the unique CDP project code (no separator or syntax characters) - PARTIAL. The CDP code format is not defined in the PDF (examples P11, P21, P101). Only emptiness and characters that break the pattern are rejected.
- **ADM-NAME-009** File extension is .dwg - PARTIAL. The stem is validated; the produced file carries .dxf because DWG is not produced yet. Flagged on every run.
- **ADM-CRS-002** Features in an arbitrary coordinate system are not accepted - PARTIAL. Detected only indirectly through ENG-CRS-003 (extent plausibility).
- **ADM-TTL-001** Each file has one Title attribute block on layer Title - PARTIAL. The Title block name/definition is only in the official template; detection relies on attribute tags from Table 4.
- **ADM-TTL-004** Title block lower-left corner inserted at a location according to the drawing plot coordinates - NOT_IMPLEMENTED. Wording is ambiguous; needs the official template or ADM clarification.
- **ADM-LYR-003** Layer DimensionLine contains AutoCAD dimensions using the template dimension style - PARTIAL. Entity type is checked; the dimension style requires the official template.
- **ADM-LYR-004** Layer Title holds the drawing title, border, textual details and the title attribute block - PARTIAL. Text, border polylines and the title block are allowed on Title; title/border content itself is not checked without the official template.
- **ADM-LYR-007** Layer name spelling follows Tables 5-7 (PDF-internal spelling variants recognised) - IMPLEMENTED. Tables and Section 6 spell some names differently (DISCREPANCIES X-02..X-05); the official template decides.
- **ADM-CAP-005B** LWPOLYLINE arc segments (bulges) - treated as arcs that should be digitised as vertices - IMPLEMENTED. Whether the official QC rejects bulge segments is unknown. An opt-in, logged densification fix is offered; never applied automatically.
- **ADM-CAP-007B** No unused blocks, unused linetypes or unused hatch styles - PARTIAL. Unused block definitions are purged from the prepared output (logged); unused linetypes are reported only. "Hatch styles" has no direct DXF table and is not checked.
- **ADM-ATT-002** Predefined attribute block structure is used unchanged - PARTIAL. Tags are compared with the Section 6 tables. Full structural comparison (prompts, order, flags) needs the official template.
- **ADM-ATT-011** Special characters, repeated characters and letter/number confusion are flagged as data-entry errors - PARTIAL. Detection is an M4 heuristic (the PDF gives no exact definition); results are warnings for review.
- **PND-TPL-001** Official ADM DWG template (layers, attribute blocks, title block, dimension style, Track linetype) - INTERFACE_ONLY. Not available. Adapter loads and compares a template once supplied; nothing is fabricated in its absence.
- **PND-QC-001** Official ADM QC tool (.FAS) and its user manual - INTERFACE_ONLY. Not available. The internal report is never official ADM QC; an official result can only be attached from a real run.
